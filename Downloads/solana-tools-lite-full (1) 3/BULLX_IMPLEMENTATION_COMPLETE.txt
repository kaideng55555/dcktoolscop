Frontend (React):
  TokenCardGrid
    ├── Generates mock token data (9 tokens)
    ├── Groups into 3 rows
    └── Renders BullXTokenCard components

BullXTokenCard:
  ├── Shows market data, price changes, sparklines
  ├── "Buy" button → triggers sniper logic
  └── "Chat" button → opens TokenGatedChat

TokenGatedChat:
  ├── Connects WebSocket: ws://localhost:8000/ws/chat/{mint}
  ├── Sends wallet for verification
  ├── Backend checks balance
  └── If verified → joins chat room

Backend (Python/FastAPI):
  @app.websocket("/ws/chat/{token_mint}")
    ├── Receives wallet address
    ├── Verifies SPL token balance
    ├── Manages chat room per token
    └── Broadcasts messages to holders

Chat not connecting?
  → Check WS endpoint: ws://localhost:8000/ws/chat/{mint}
  → Verify wallet is connected
  → Check browser DevTools console for errors

Cards not showing?
  → Verify mock data in TokenCardGrid.tsx fetchTokens()
  → Check token data structure matches interface
  → Look for TypeScript errors in console

Balance verification failing?
  → Current implementation uses mock balance
  → Replace with QuickNode/Helius API for production
  → Check error logs in backend console

Slow performance?
  → Reduce number of cards or use pagination
  → Cache token data for 10-30 seconds
  → Consider using Redis for chat scaling

Mobile layout issues?
  → Components are fully responsive
  → Chat panel becomes full-screen on small devices
  → Adjust panel width in TokenGatedChat.tsx if needed
