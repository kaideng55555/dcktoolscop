🎮 HOW TO USE

   - View all snipes
   - Recent transactions first
   - Amount, price, timestamp
   - Status: Pending/Success/Failed

4. MONITOR PRICES (📊 tab)
   - Current SOL price (left)
   - 24h high/low
   - RSI & SMA indicators
   - Set price alerts (right)
   - Get notified when triggered

      await chat_handler(websocket, token_mint)

⚙️ CUSTOMIZATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Change Colors:
  Edit getRowColor() function in UnifiedApp.tsx
  new: '#00d4ff' → any color
  trending: '#00ff00'
  top: '#ffaa00'

Change Holder Ranks:
  Edit verifyTokenBalance() function
  Whale: >1000000 → change threshold
  Hodler: >100000
  Holder: >1000

Change Chart Grid:
  gridTemplateColumns: 'repeat(auto-fill, minmax(280px, 1fr))'
  280px → wider/narrower cards

Change Chat Requirements:
  setVerified(mockBalance > 100)
  100 → any minimum balance
